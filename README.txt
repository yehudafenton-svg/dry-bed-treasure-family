Dry Bed Treasure - Shared Money Box
===================================

OPEN THE APP
https://yehudafenton-svg.github.io/dry-bed-treasure/

This is an installable mobile web app for Android and iPhone. It rewards dry
mornings with growing coins in a money box. The first seven calendar days can
earn a total of $5, then each following 14-day period can earn a total of $5.
Non-dry mornings never take away money already earned.

It works locally without setup. For live syncing on both parents' phones,
follow SETUP-GUIDE.txt. You must create a Firebase project, enable Anonymous
Auth and Cloud Firestore, publish firestore.rules.txt, and supply your four
Firebase web config values in firebase-config.js. Sharing will then be enabled.

The money box's private invite code is secret. Never post it publicly.
Always make a backup before changing the app or connecting to a different box.
